# Behavioral results — 2026-08-14

## Method

Each execution below used a newly spawned context. The runner was told to read the revised skill and applicable references, act on one user scenario, return only the user-facing response, and make no repository edits. Results were graded against `rubric.md` by observable output. The collaboration runner exposed final responses but not nested skill-invocation traces.

The 48-case contract is defined in `scenarios.md`. This run selected high-risk representatives and multiple replicas for Stage 1. It does not claim that every one of the 48 specified cases received a separate model execution.

## Pre-change baseline

Five fresh-context replicas against the old skill all preserved the user's voice and core insight, but all five failed to offer 2–3 narrative directions and failed to surface the bilingual default. See `baseline.md`.
